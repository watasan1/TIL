# Git ブランチ（branch）について

## ブランチとは

Gitではリポジトリ内で複数の「作業の流れ」を並行で管理できる仕組みがブランチです。

Gitのブランチは、複数の作業をお互いに影響を与えずに、並行して進めることができます。

## gitのBranchの基本コマンド

- `git branch`: ブランチ一覧を表示
- `git branch <ブランチ名>`: 新しいブランチを作成（切り替えはしない）
- `git switch <ブランチ名>`: ブランチを切り替え
- `git switch -c <ブランチ名>`: ブランチを作成して切り替え
- `git push`: コミット済みのリモートリポジトリに変更を反映

## なぜ重要か

Gitのbranch機能がなぜ重要なのか？

1. mainブランチを安全な状態保てる
  動作確認が済むまで本流に影響を与えないため。

2. 複数の作業を並行して進められる
  機能A・機能Bなどを互いに干渉させずに進められるため。

3. チームでの共同作業がしやすくなる
  各自のブランチ + PRでレビューを挟んでmainにマージできるため。
