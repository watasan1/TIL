# 私の学習サイクル

作成日: 2026-10-13

## 学習サイクル

わからないことを「調べて → 試して → 記録して → 発信して → 振り返る」の流れで学びます。

```text
1. 調べる（インプット）
   ↓
2. 試す（チャレンジ）
   ↓
3. 記録する（メモ・整理）
   ↓
4. 発信する（アウトプット）
   ↓
5. 振り返る
   ↓
次の「わからない」を見つけて 1 へ戻る
```

## 決めたこと

### いつ

- 毎日

### ツール

| ステップ | 使うツール | 使い方 |
|---|---|---|
| 調べる | 公式ドキュメント | その日の Mission を進める。気になったことは Issue にためる |
| 試す | Git Branch / GitHub Pull Request | ブランチを切ってコードを書き、動かして確かめる |
| 記録する | TIL、GitHub Discussions | 学んだことは TIL に、作業中のメモや悩みは Discussions に |
| 発信する | Discord | 日々の取り組みを「みんなの雑メモ」に投稿する |
| 振り返る | 週次振り返り、Will/Can/Must | 週 1 で振り返り、目標を見直して次の Issue を作る |

### 小さく始める

- 1 日 1 Mission を目安に進める
- TIL は完璧を目指さない
- わからないことは 30 分調べて解決しなければ、Discussions や Discord で質問する

## 1 日の流れ

- 毎日: React の Mission で学ぶ → コードを書いて動かす → TIL に記録する → Discord に共有
- わからないとき: 調べる → 試す → Discussions に記録 → 解決したら TIL にまとめて共有
- 週 1: 振り返り（Will/Can/Must を見直す）→ 来週やることを Issue にする

このサイクルは一度作って終わりではなく、週次の振り返りで続けやすい形に改善していきます。
