# TIL: GitHubプロフィールREADMEを作成した

## 今日やったこと

GitHubのプロフィールページに、自己紹介用の「プロフィールREADME」を作って表示させた。

## 学んだこと

### 1. プロフィールREADMEは「自己紹介カード」

`https://github.com/ユーザー名` を開いたとき、最初に目に入る自己紹介エリア。
次のような点で大事だとわかった。

- 第一印象: どんな人で、何に取り組んでいるかがすぐ伝わる
- つながり: 同じ技術や興味を持つ人と出会うきっかけになる
- 学習の記録: 自分の成長を見返せる

### 2. ユーザー名と同じ名前のリポジトリが「特別なリポジトリ」になる

プロフィールREADMEを作る手順はとてもシンプルだった。

このリポジトリの `README.md` が、そのままプロフィールページに表示される仕組み。

## 魅力的なプロフィールにするコツ

- 訪問者が10秒で理解できる内容にする
- 情報を詰め込みすぎず、シンプルにする
- 学習の進み具合に合わせて定期的に更新する
- 遊び心を持って、自分らしさを出す

## 感想

リポジトリ名をユーザー名にするだけで特別な扱いになる仕組みがおもしろかった。
画像URLを貼るだけでStatsやバッジが表示されるので、少ない手間で見た目が華やかになった。
これから学習が進んだら、スキルや実績を追加して育てていきたい。
