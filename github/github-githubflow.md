# Githubのgithubflowとは？

作成日: 2026-10-21

## 学んだこと

GitHub Flowは、多くの開発チームで採用されているシンプルな開発ワークフローです。
mainブランチから作業用のブランチを作り、変更をコミットしてプルリクエストでレビューしてもらいます。
問題がなければmainブランチにマージすることでmainを常に動く状態を保ちながら開発が進められます。
多くの企業やオープンソースプロジェクトで、この流れが採用されています。今から慣れておくことで、チーム開発にスムーズに参加できます。
