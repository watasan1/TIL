# TIL: GitHubプロフィールにSNSやブログのリンクを追加する

## 今日学んだこと

GitHubのプロフィールには、SNSやブログ、ポートフォリオへのリンクを載せられる。
リンクを置いておくと、プロフィールを見た人にGitHub以外の活動も知ってもらえる。

## 登録できるリンクは最大5つ

| 入力欄 | 登録できる数 | 向いているリンク |
| --- | --- | --- |
| URL | 1つ | ブログ、個人サイト、ポートフォリオ |
| Social accounts | 最大4つ | X / Bluesky、LinkedIn、Qiita / Zenn / note、YouTube、Speaker Deck など |

## リンクを載せるときのポイント

- よく使っているアカウントを優先して載せる
- リンク切れがないか確認する
- リンクは誰でも見られる。本名や居住地など個人情報が分かるアカウントは避ける
- 定期的に見直す（新しいSNSを足し、使わなくなったものは消す）

## 感想

設定自体は10分ほどで終わるが、プロフィールの見た目と情報量がかなり変わる。
GitHubを「コード置き場」だけでなく、自分の活動の入口として使えると分かった。
