# GitHubのDiscussionとは？

作成日: 2026-08-18

## 学んだこと

GitHub Discussions は、リポジトリ上で質問・議論・情報共有などのコミュニケーションを行うための機能です。

## 詳細・メモ

Discussionsは「質問・議論・情報共有などの会話」に向いています。

Discussionsに書くと便利なものは、完了条件がない

- 学んだこと・気づきの共有
- 相談
- 振り返り

「残しておいて後から参照・会話を続ける」ものは Discussions、と考えると迷いにくいです。
